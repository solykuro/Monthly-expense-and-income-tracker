# 新增固定收支規劃工具

## Why

市面上的記帳工具著重在「過去花了什麼」，無法回答長期規劃最重要的問題：**每個月可以放心投入股市的金額是多少？**

使用者手邊不留太多現金，每月盈餘會投入股市。因此真正的風險不是「存款不夠多」，而是年繳保險、季繳費用、稅金等非每月支出到期時，手頭剛好沒有錢。使用者需要一個能長期推演固定收支的工具：把非每月支出平均攤成每月應預留的金額，扣除後得到每月可投資金額，並提前指出哪些月份會入不敷出。

這是全新專案，第一版以個人使用、隱私優先、開發量小為原則，做成資料只存在手機本機的 PWA。

## What Changes

- 新增收支項目管理：名稱、收入或支出、金額、週期（每月／每季／每半年／每年）、發生月份與日期、開始與結束月份、分類
- 新增金額異動紀錄：同一個項目可以設定多筆「從某月起改為某金額」
- 新增現金流推演：以目前月份為起點，推演 1／3／5／10 年（預設 5 年）
- 新增預留金模型：非每月支出依「剩餘月數平均分攤」計算每月應預留金額，並自動處理來不及累積時的追趕
- 新增初始預留金設定：依到期先後分配給各非每月支出
- 新增每月可投資金額計算：當月收入 − 當月每月支出 − 當月應預留
- 新增總覽畫面：摘要卡片、逐月／逐年表格、月份明細、可投資金額長條圖、入不敷出警示、追趕預留提示
- 新增 JSON 匯出與匯入（匯入為完全取代）
- 新增 PWA 外殼：可加入主畫面、離線使用、底部分頁導覽、請求持久化儲存

## Non-goals

- 逐筆記帳或記錄日常花費
- 年成長率、投資報酬、資產成長推演
- 目標導向規劃（例如某年存到某金額）
- 登入、雲端同步、多人或多裝置即時共用
- 推播通知、扣款提醒
- 追蹤實際帳戶餘額或實際扣款狀態
- 匯入時合併資料
- 自訂分類、多幣別
- 原生 iOS／Android App

## Impact

- Affected specs（全部為新增）：
  - `budget-items`：收支項目、週期、金額異動紀錄、本機保存
  - `cashflow-projection`：推演期間、預留金與可投資金額的計算規則
  - `projection-dashboard`：總覽畫面與警示
  - `data-backup`：JSON 匯出與匯入
  - `app-shell`：PWA 安裝、離線、導覽、持久化儲存
- Affected code（全新建立）：
  - `src/domain/`：型別、月份工具、驗證、推演純函式
  - `src/db/`：Dexie 資料庫與存取
  - `src/features/items/`、`src/features/dashboard/`、`src/features/settings/`：畫面元件
  - `src/features/backup/`：匯出與匯入
  - `vite.config.ts`：PWA 設定
